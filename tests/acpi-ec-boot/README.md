# ECDT boot-table decoding and namespace path tests

Run inside the Nix environment, exporting TMPDIR before entering it:

```sh
export TMPDIR=/home/doc/cubit-build-tmp
nix develop --command bash tests/acpi-ec-boot/run.sh
```

`--validate-only` checks input hashes without executing. `--source-root DIR`
selects an explicit matching source tree. Outputs are private, nice19/j1, with
180s build/30s runtime/5s fixture commands, stack64MiB/core0 and logs≤1MiB.
Both checked (assertions+overflow) and release profiles reject warnings; the
runner verifies source hashes and actual ALI switches.

The retained template was generated by pinned ACPICA20260408 iASL `-T ECDT`.
Its Intel copyright header is preserved. Fixtures add a rooted path and a
separate memory-address example without suppressing diagnostics or forcing
compilation. iASL compiles all three tables normally; IO and memory fixtures
are disassembled and recompiled, requiring exact complete binary equality.
The independent reference includes the original empty-path template; the
structural decoder accepts its terminated field but path parsing rejects it.

The256checks/profile exercise control/data ordering, full64-bit unaligned
memory addresses, UID/GPE values, exact length/checksum, every truncation and
single-byte checksum mutation, checksum-valid short fixed fields, arbitrary
array origins including Positive'Last, ASCII termination, malformed names,
short-name underscore padding,255/256segment limits, suffix retention, unknown
revision/space/access claims and alias/IO-width classification. Zero addresses
remain descriptions, not an absent-register assumption or permission.

This is hosted parser testing plus ACPICA data-table compile/disassemble/
recompile evidence. It is not hardware, ECDT boot integration, namespace
binding, register admission, Global Lock, SCI/GPE routing or SPARK proof.
SPARK_Mode and checked postconditions are enabled; no new formal proof is
claimed. The full verified userspace ACPI/AML goal remains incomplete.

Normative layout: ACPI6.6 section5.2.15:
https://uefi.org/specs/ACPI/6.6/05_ACPI_Software_Programming_Model.html#embedded-controller-boot-resources-table-ecdt
