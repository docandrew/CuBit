# Native ACPI HID discovery pass

This hosted suite executes the actual ACPI_Native_HID_Detection body against
actual Requests/Core/AML, with logger delivery modeled. Checked/release each312
checks,20fresh processes/profile,32/64bit AML,52commands including ordinary iASL
fixture compilation. Covers two candidates past controllers,empty namespace,
readiness refusal,missing GPIO,byte/fuel/candidate budgets,retained-CRS cleanup,
exact firmware facts,bounded stage logs and terminal no-replay across owners.

Run run.sh in pinned Nix with TMPDIR=/home/doc/cubit-build-tmp before and inside
it. run.mjs --validate-only checks source hashes without execution. Source and
compiler/profile hashes are audited; builds180s,each runtime30s,stack64MiB,
logs1MiB,nice19/j1. ACPICA's previously recorded exact budget-fixture reference
is reused only after checking byte-identical AML; its known14cache-allocation
exit diagnostic remains qualified. No new independent oracle run is implied.

The native pass runs once before observer registration/IPC on the same private
Core. It uses fixed evaluators and one total AML budget, owns no hardware or
launcher endpoint, and grants no authority from resource descriptions. Defaults:
10000AML fuel,65536CRS bytes,4candidates,256bytes/source or vendor span. Limits
are explicit local diagnostic policy,not ACPI limits; reaching one is reported
as incomplete/refused. CandidateLimit is not full enumeration success.

Only current complete I2C/GPIO source resolutions produce resource fact lines.
The pass stops at the first failure. No buffer retry reexecutes firmware. Every
outcome is latched; a later Run returns the same report without AML/log replay.
Uncertain retained cleanup keeps the process-lived probe/Core and stops startup
before registration. Native provider/source attachment,launcher admission,input
publication,link/stack fit,QEMU/laptop execution and full SPARK proof remain open.

## HID recovery milestone review

Recovery is now separate from retained-CRS cleanup. Fatal/Field/provider
uncertainty during identity,status,resource or descriptor observation prevents
subsequent power AML and registration,even with no retained value pending.
In-flight calls keep conservative recovery; unexpected exceptions latch
Owner_Error. Normal budget/resource refusal remains distinct. No automatic
retry/reset or authority change. Native main checks both cleanup and recovery.

## Native retained channel rows

The actual pass now instantiates the typed channel adapter and retains complete
rows with original resolved device/controller identities and all copied facts.
The matrix checks exact address, speed, pin/signaling and descriptor register;
unused/refused rows are empty. Producer-role refusal stops before publishing a
row; a later refusal retains only the earlier complete prefix. Seventeen
fixture candidates test the16-row bound and incomplete Candidate_Limit outcome.
Logger failure publishes no row, and repeated calls return the same historical
report without executing AML or changing another Core.

These rows are descriptive data, not readiness, authority, or a frozen view of
firmware state. Native launcher handoff and revalidation, backend admission,
event enrollment, hardware behavior and full SPARK proof remain unfinished.
