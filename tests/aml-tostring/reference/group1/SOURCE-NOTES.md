# ToString independent oracle source plan

Pinned primary exoparg2.c447–490 constructs a fresh String with raw Buffer prefix length=min(BufferLength,requestedLength,firstNUL). exresop.c536/566 performs implicit integer length and Buffer source conversions; exconvrt.c gives integer little-endian width and String bytes+terminator. FIXED_TARGET does not imply implicit destination-type conversion: differing target kinds replace, matching String updates destination value. exstoren.c320–390 and exstorob.c307–329 distinguish value/object updates and backing storage replacement.

The safe held-byte alias test dynamically creates length3 destination then shrinks to2, with a read of retained Index0 before/after (88 then65). Equal/growing String storage may free/reallocate the raw IndexPointer (exoparg2.c527/540), so earlier same-length pointer observations are excluded from requirements. Direct result-to-Local alias is tested by mutating Index(ToString(...,Local0),0) directly, without an intervening Store copy. Named target result independence uses the same direct-expression pattern.

Every normally compiled input is DSDT revision1 or2 and is loaded alone. tbinstal.c215–218 sets integer width from DSDT only; WIDT=ShiftRight(Ones,32) must return0 for revision1 andFFFFFFFF for revision2 before TEST is run. Previous SSDT revision-labeled experiments were not valid width evidence and are historical only. Their original raw scripts/logs remain in sibling directories, never relabeled as DSDT runs.

ToBuffer wrappers expose exact returned String bytes plus their added NUL. Separate ObjectType/SizeOf witnesses establish type2 and logical length2/3. Wrapper bytes alone do not prove native String type or length. All case sources compile normally with iasl -oa; no forced compile. Direct Package and direct Index compiler rejections remain compiler results, not runtime errors. Method disassembly retained to detect folding/admission differences. Per-process bounds128MiB address space,64MiB stack,5seconds; pinned Nix host, nice19. Earlier first failed harness used1GiB/30seconds, recorded as a deviation and not repeated in corrected set.

No CuBit interpreter changes, tests, proof or compatibility pass claimed by this ACPICA-only evidence. Known exact cache-allocation shutdown warnings are retained separately; successful return does not establish clean ACPICA teardown. Unexpected diagnostic text fails the harness for successful results. Runtime failures retain complete diagnostics and marker effects.
