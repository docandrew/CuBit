# HID offer payload v1

Export `TMPDIR=/home/doc/cubit-build-tmp` before Nix and run `run.sh` in the
pinned environment. The runner freezes the actual pure shared codec, protocol
declaration and runtime CuBit parent, fixtures and independently generated
golden byte strings in a unique temporary output directory. Checked and release
builds have bounded compilation/runtime, one worker, explicit fixture checks
and strict warnings. Node20.11 or newer is needed for `import.meta.dirname`.

The independent JS layout checks normal, fully populated maximum-width and
unresolved-PCI observations against Ada encoding. Cases cover all four raw
spans, full64-bit epochs/UIDs, exact little-endian fields, every truncated
prefix, trailing bytes, malformed fields/enums/counts/padding, and array bounds
at17 and Natural'Last. Unresolved PCI presence is preserved rather than replaced
with a guessed bus0. Malformed decoding releases no partial row. UID string
words are opaque and preserve the prior accepted GPIO record's exact value.

This suite validates serialization and canonical shape, not physical/resource
authority, observation freshness, the native producer/grant controller, devmgr
receipts/launch, or hardware. SPARK-compatible declarations/contracts are not
a new proof claim. Behavior comes before the codec/policy proof milestone.
See the committed test-local `WIRE.md` for offsets and the peer validation obligations.

The suite has no docs/ or coordination-mail dependency. WIRE.md is pinned test
data for the independent JS golden layout; no Ada encoder constants are parsed.
