Hosted MCFG structural parser checks: run run.mjs with the pinned Nix Ada toolchain and TMPDIR=/home/doc/cubit-build-tmp. Checks asserted/release profiles, extent/count, literal decoded values, truncations, invalid indices and non-default array origins. No hardware authority or complete ACPI semantics claim. Proof evidence is independently scoped in the milestone checkpoint.
Run prove.mjs for fresh level1/2 proofs of the actual shared SDT and MCFG readers with the pinned GNATprove/CVC5 tools. Each run is bounded to180seconds/j1 and checks106proof+15flow obligations, full SPARK bodies, exact source/tool hashes and no skipped/unproved/Assume checks. The proof does not establish all byte/checksum semantics or memory authority.
After run.mjs, run reference.mjs with ACPICA iASL on PATH. It disassembles the exact fixtures emitted by both test builds and checks six raw MCFG fields per profile; it does not execute AML or establish mapping authority.
