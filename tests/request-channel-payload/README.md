# Request channel payload regression

Run `TMPDIR=/home/doc/cubit-build-tmp nix develop -c bash tests/request-channel-payload/run.sh`. Both assertion-enabled and release hosted profiles check persistent payload views and ownership, then compare the actual production Lexicon/IPCTest layouts to the recorded pre-extension layout. Golden fields, in order for each channel: request/result size in bits, request/completion ring bytes, client/server pages, ring offset, client-state offset, status offset. Lexicon pages remain 9/9, IPCTest 2/2, ring offset 4096. The only modeled production dependency is Messages.DRIVER_LEXICON (28); its production source is pinned and the constant checked. Ordinary arrays model shared pages; kernel read-only enforcement is assumed, not tested. No new proof/native execution is claimed.
