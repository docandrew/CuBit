# Observer source identities

Run `bash tests/acpi-source-identities/run.sh` in the pinned Nix development
shell with `TMPDIR=/home/doc/cubit-build-tmp`. The closed catalog records actual
pure path packing and native identity dispatch code, with explicit request,
message, endpoint encoder and domain models. Checked and release profiles run
identical exhaustive path-length/offset and request-refusal cases. Domain
callback counts distinguish validation from metadata access.

The `joined/identity_events` helper is also used in the private actual-root
startup harness. It runs the real AML interpreter, inventory collectors,
metadata path reader, caches, event domain, native endpoint and original native
owner callback. Its inherited hosted kernel, platform, clock, server and final
wait boundaries remain models. Its hosted namespace capacity is256 nodes, enlarged
from the inherited128 to hold the156 named-object overlong-path fixture.
Production limits are unchanged. `identities.asl` supplies nested AC/battery
locations, an overlong source path and an explicit inventory reorder. Those
joined results are recorded separately; this standalone runner does not execute
them. Neither runner establishes native execution or hardware acceptance.

Observer identity page23 is documented in
`shared/acpi/acpi_power_identity_protocol.ads`. Obtain page21 or page22's family
cache generation before reading chunks; reject and restart a name if that
family generation changes. Seven-byte chunks fit a positive signed64 integer.
A namespace path identifies the firmware source location across slot changes,
not a physical battery across replacement. It grants no callable authority.
