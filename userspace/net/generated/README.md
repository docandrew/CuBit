# Generated parsers and serializers

Pristine output of AdaCore RecordFlux **0.26.0** for the specifications in
`../specs/` (see `../NOTICE`). Never edit these files: change a
specification and regenerate.

Generated outside Nix and committed (the build never runs RecordFlux):

    rflx generate --ignore-unsupported-checksum -p Net -d generated \
        specs/ethernet.rflx specs/arp.rflx specs/ipv4.rflx specs/icmp.rflx \
        specs/udp.rflx specs/tcp.rflx specs/protocol_numbers.rflx

run from `userspace/net`. `-p Net` puts every unit under the `Net` parent
package (netstack's `Net`), library units included (`net-rflx_*`), which
are unmodified.

RecordFlux 0.26.0 is on PyPI (`pip install RecordFlux==0.26.0`; its `z3`
bindings need `libstdc++` and `libgmp` on the library path).

Checking for drift: regenerate into a scratch directory and compare,
ignoring the generation-date line:

    diff -r -I 'Generated by RecordFlux' generated <scratch>
